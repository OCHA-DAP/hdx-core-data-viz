# HDX Lens

**HDX Lens** is an interactive Gapminder-style explorer for humanitarian crisis data. It draws from OCHA's [Humanitarian API (HAPI)](https://source.coop/hdx/hapi) to plot countries and regions on axes like conflict fatalities, food insecurity, poverty, and displacement — letting you compare across crises, drill from country to sub-region, and step through years. All data loads directly in the browser; no account or download needed.
